# Bearers: What Lingers Matters

A streamlined, classless, level-less tabletop roleplaying game played with cards.
Each Bearer is born to a **Calling**, a pair of abilities kept for life. Everything else is a card in a **Slot**: gear you equip, and **Runes** (Traits, Techniques, Domains and decks of magic) you etch into yourself, caught in **Runestones** when a foe dies or given by a willing creature. Swap cards at rests to change who you are.

- Play loop: a **story** of **quests**, each made of **challenges** (face → gather → rest & rebuild), with exploration between challenges
- Power grows through card Rank (I to V), never through levels
- Setting-agnostic (for now)

## Building the PDF
```
.venv/bin/pip install markdown
.venv/bin/python tools/build_pdf.py
```
The base set: `.venv/bin/python tools/build_cards.py` (also regenerates `sim/cards.js` and `cards/tables/`). Balance report: `python3 tools/balance_report.py`. The combat cheat sheet: `.venv/bin/python tools/build_cheatsheet.py`.

French edition: add `--lang fr` to any of the three builds (`build_pdf.py`, `build_cards.py`, `build_cheatsheet.py`); the PDFs go to `rules/fr/`. A rule change in English needs the same change in `rules/fr/`, `cards/fr.py` (card text) and `tools/cheatsheet_fr.py`; the card build stops on any untranslated card text.

Needs Chromium. Fonts (Cinzel, EB Garamond) load from Google Fonts at build time.
